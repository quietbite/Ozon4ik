# Ozon4ik: ML-модули для веб-сервиса электронной коммерции

Учебный прототип веб-сервиса электронной коммерции с тремя ML-модулями:

- **Рекомендации** товаров на основе истории действий пользователей;
- **Ранжирование поиска** по категориям товаров;
- **Динамическое ценообразование** с подбором цены по максимуму выручки.

## Стек

Python 3.11/3.12, pandas, numpy, implicit (ALS), LightGBM (LambdaRank), rank-bm25, CatBoost, scikit-learn, FastAPI, Streamlit. Хранение: CSV (исходные данные), parquet (обработанные данные), joblib (модели), JSON (конфигурация и метрики).

## Данные

- **RetailRocket** (Kaggle, Roman Zykov): `events.csv`. Используется для рекомендаций.
- **Olist** (Kaggle, olistbr): таблицы заказов, товаров и категорий. Используется для поиска и ценообразования.

> **Ограничение:** идентификаторы товаров в двух датасетах не совпадают, поэтому они не объединяются. Каждый модуль обучается на своём источнике.

## Методология

- **Веса событий** в рекомендациях: просмотр = 1, добавление в корзину = 3, покупка = 5.
- **Разбиение на train/test** по времени, порог 80% событий. В тест попадают только пользователи из train (холодный старт).
- **Поиск:** LambdaRank, тест на категориях, которых не было в обучении.
- **Ценообразование:** CatBoost на недельных продажах, временной тест на последних 8 неделях, подбор цены в диапазоне ±20% по максимуму выручки.

## Ограничения

- Цены товаров в Olist почти не меняются, поэтому эффект изменения цены виден слабо.
- Сквозной сценарий «рекомендация → поиск → цена» работает на разных датасетах.
- Парсинг Ozon и других маркетплейсов не используется: это нарушает условия использования сервисов и нестабильно.
- Проект учебный, не продакшн.
