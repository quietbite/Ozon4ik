# Ozon4ik: ML-модули для веб-сервиса электронной коммерции

Учебный проект: прототип веб-сервиса электронной коммерции с тремя ML-модулями:

- **Рекомендации** товаров на основе истории действий пользователей;
- **Ранжирование поиска** по категориям товаров;
- **Динамическое ценообразование** с подбором цены по максимуму выручки.

Проект демонстрирует полный путь от данных до работающего интерфейса: очистка, обучение моделей, оценка на временной выборке, API и веб-интерфейс.

## Стек

- **Язык и данные:** Python 3.11/3.12, pandas, numpy, pyarrow, matplotlib, Jupyter
- **Модели:** implicit (ALS), LightGBM (LambdaRank), rank-bm25, CatBoost, scikit-learn, scipy
- **Бэкенд:** FastAPI, uvicorn
- **Интерфейс:** Streamlit
- **Хранение:** CSV (сырые данные), parquet (обработанные данные), joblib (модели)

## Данные

- **RetailRocket** (Kaggle, Roman Zykov): файл `events.csv`. Используется для рекомендаций и разбиения на train/test.
- **Olist** (Kaggle, olistbr): таблицы `olist_order_items_dataset.csv`, `olist_products_dataset.csv`, `olist_orders_dataset.csv`, `product_category_name_translation.csv`. Используется для поиска и ценообразования.

Сырые данные не хранятся в репозитории. Их нужно скачать с Kaggle и поместить в `data/raw/`.

> **Ограничение:** идентификаторы товаров в RetailRocket и Olist не совпадают, поэтому два датасета не объединяются. Каждый модуль обучается на своём источнике.

## Структура проекта

```
ozon_ml/
├── data/
│   ├── raw/            # исходные CSV (не в git)

├── src/
│   ├── data.py          # загрузка и очистка
│   ├── recommender.py   # рекомендации (ALS)
│   ├── search_ranker.py # ранжирование поиска (LambdaRank + BM25)
│   └── pricing.py       # ценообразование (CatBoost)
├── scripts/
│   ├── train_all.py         # обучение всех моделей, сохранение в models/
│   └── check_recommender.py # проверка рекомендаций
├── api/
│   └── main.py          # FastAPI: эндпоинты поиска, рекомендаций, цен
├── app/
│   └── app.py           # Streamlit-интерфейс
├── models/              # bundle.joblib (создаётся train_all.py)

```

Логика моделей находится в `src/`. Интерфейс и API только вызывают эти функции.

## Методология

- **Веса событий** в рекомендациях: просмотр = 1, добавление в корзину = 3, покупка = 5.
- **Разбиение на train/test** по времени: порог 80% событий. В тестовую выборку попадают только пользователи, которые есть в train (холодный старт обрабатывается так).
- **Поиск:** LambdaRank, тест на категориях, которых не было в обучении.
- **Ценообразование:** CatBoost на недельных продажах, временной тест на последних 8 неделях, подбор цены в диапазоне ±20% по максимуму выручки.

## Известные ограничения

- Цены товаров в Olist почти не меняются, поэтому эффект изменения цены на продажи виден слабо.
- Датасеты разные по доменам и идентификаторам, поэтому сквозной сценарий «рекомендация → поиск → цена» работает на разных данных.
- Парсинг Ozon и других маркетплейсов не используется: это нарушает условия использования сервисов и нестабильно.
- Проект рассчитан на учебный прототип, а не на продакшн.

## Установка

Требуется Python 3.11 или 3.12.

```bash
git clone https://github.com/<your-username>/ozon_ml.git
cd ozon_ml
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

Скачайте датасеты с Kaggle и положите CSV-файлы в `data/raw/`.

## Запуск

1. Обучить модели и сохранить их в `models/`:
   ```bash
   python scripts/train_all.py
   ```
2. Запустить API:
   ```bash
   uvicorn api.main:app --reload
   ```
   Документация эндпоинтов доступна на `http://127.0.0.1:8000/docs`.
3. Запустить веб-интерфейс:
   ```bash
   streamlit run app/app.py
   ```
